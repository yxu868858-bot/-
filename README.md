# 义巷·漫游集 —— 动态汇报

义乌垂直楼项目景观方案设计（2026.10）的网页动画汇报版。共 99 页，与原方案 PDF **逐页对应、页码一致**，原文的文字信息全部保留。

## 打开方式

- **单文件版（推荐分享）**：`dist/义巷漫游集-动态汇报.html`，图片已内嵌，用浏览器打开即可播放。
- **源码版**：`index.html` + `assets/img/`，需保持目录结构。
- 地址后加 `?autoplay` 自动播放；加 `#36` 直接跳到第 36 页（与 PDF 页码相同）。

## 操作

| 操作 | 按键 |
| --- | --- |
| 下一页 / 上一页 | → / ←、空格、点击画面（点左侧 1/4 为上一页）、手机左右滑动 |
| 自动播放 / 暂停 | P 或底部「自动播放」按钮 |
| 全屏 | F |
| 目录（跳转任意页） | M |
| 首页 / 末页 | Home / End |

## 图片素材

`tools/make_assets.py` 从方案 PDF 生成 `assets/img/`（需 `pip install pymupdf`）：

- 效果图、照片：直接导出 PDF 内的原始 JPEG，不做二次压缩；
- 平面图、分析图：按区域高分辨率渲染，保留矢量标注。

分析图的"生长"动画由 `tools/make_layers.py` 生成（输出到 `assets/layers/`）：按 PDF 的绘制顺序逐个对象渲染，相邻两次渲染的差异即为一层，播放时底图之上的色块、色带、箭头、标签依次长出，最终画面与原图一致。要给其他页面加同样效果，在脚本的 `TARGETS` 中加上该图的页码与区域即可。

PDF 内嵌效果图的原始分辨率为 1191×737 像素，满屏播放会偏软。如有高清原图，用同名文件替换 `assets/img/` 中对应的图片即可（效果图命名为 `r` + PDF 页码，例如第 36 页为 `r36.jpg`），再运行 `python3 build.py` 重新生成单文件版。
