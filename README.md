# 义巷·漫游集 —— 动态汇报

义乌垂直楼项目景观方案设计（2026.10）的网页动画汇报版，内容根据原方案 PDF（99 页）整理，共 44 页、6 个篇章。

## 打开方式

- **单文件版（推荐分享）**：`dist/义巷漫游集-动态汇报.html`，图片已内嵌，双击即可在浏览器中播放。
- **源码版**：`index.html` + `assets/img/`，需保持目录结构。
- 地址后加 `?autoplay` 可自动开始播放；加 `#12` 可直接跳到第 12 页。

## 操作

| 操作 | 按键 |
| --- | --- |
| 下一页 / 上一页 | → / ←、空格、点击画面（点左侧 1/4 为上一页）、手机左右滑动 |
| 自动播放 / 暂停 | P 或底部「自动播放」按钮 |
| 全屏 | F |
| 目录（跳转任意页） | M |
| 首页 / 末页 | Home / End |

## 更新

修改 `index.html` 后运行 `python3 build.py` 重新生成单文件版。字体来自 Google Fonts，离线时自动回退为系统字体。
